第 1 / 12 步

先换一个心智模型：渲染管线 vs 请求管线

你现在的直觉是"页面 = 状态 + 模板"。数据变了，Vue 重新渲染，屏幕更新。整条链路在你自己的进程里，同步、可预测、出错有 Vue 的警告帮你兜着。

后端不是这样。后端是"字节进 → 字节出"的管线。一端连着网络（不可信、会超时、会断），另一端连着数据库（会锁、会慢、会挂），中间夹着你的业务代码。你写的函数不是被 Vue 调用的，是被一个你看不见的循环调用的。

前端经验类比
和 Vue 的组件树对照

Vue 里数据流是单向的：state → computed → render。后端里数据流也是单向的，但方向相反：request → parse → validate → handle → persist → response。Vue 里你关心"渲染结果对不对"，后端里你关心"输入是否可信、输出是否合规"。前者错了用户看到花屏，后者错了用户看到别人的数据。

一次请求的完整链路
浏览器                     网络                    你的 Node 进程              存储
──────                    ────                    ─────────────              ────
fetch('/api/notes')
  │
  ├─ 1. 拼 URL、查 DNS ──────► DNS 服务器
  ├─ 2. 建 TCP 连接 ────────► 三次握手 ─────────► listen(3000) 的 socket
  ├─ 3. (https) TLS 握手 ───► 证书校验
  ├─ 4. 写请求报文 ─────────► ────────────────► 5. request 事件
  │                                                │
  │                                              6. 路由匹配
  │                                              7. 读 body（流）
  │                                              8. 校验参数
  │                                              9. 查库 ──────────────► PostgreSQL
  │                                             10. 组装响应
  │◄── 11. 响应报文 ────────◄────────────────────┘
  ├─ 12. 解析、resolve
  └─ 13. ref.value = data → 重新渲染

这张图上有 13 个位置，每一个都能出问题，而且症状完全不同。你以前只见过第 13 步的结果——"数据没出来"。这一课的目的就是让你在第 13 步看到异常时，能立刻判断问题在第几步。

症状最可能出问题的位置排查手段
fetch 直接 reject，控制台红字 "Failed to fetch"第 2 步（连不上）或第 3 步（TLS）或 CORS 预检被拒curl -v 看是否能建连；看 Network 面板的 Timing
请求发出去了，一直 pending第 5 步没触发（服务没起/端口错）或第 9 步卡住在服务里打日志；看服务进程是否活着
返回 200，但 body 是空的第 10 步写了 header 忘了 end，或提前 return检查每个分支是否都有 res.end()
返回 500，日志里没报错第 10 步之前抛错且没被捕获加 process.on("uncaughtException")
本地正常，线上 404第 6 步路由前缀不同（nginx 反代去掉了 /api）看 nginx 的 proxy_pass 是否带尾斜杠
★这一课最值钱的一句话

"Failed to fetch" 这个错误信息是浏览器故意模糊的——它不告诉你是 DNS 错、连不上、证书错、还是 CORS 被拒，因为精确信息会泄漏内网结构。所以你不能靠这句话定位，只能靠分层排查。学会分层，比记住任何一个 API 都重要。

找 bug：这个接口有三个问题

下面这段代码在本地测通了，上线后出现三种症状：① 偶尔有请求一直不返回 ② 有人发 50MB 的 body 后服务崩了 ③ 前端拿到的错误提示里出现了数据库表名。找出这三处问题。

createServer(async (req, res) => {
  const url = new URL(req.url!, 'http://localhost')

  if (url.pathname === '/api/notes' && req.method === 'POST') {
    const body = await readBody(req)          // 无大小限制
    const note = await db.note.create({ data: JSON.parse(body) })
    res.setHeader('Content-Type', 'application/json')
    res.end(JSON.stringify(note))
    return
  }

  if (url.pathname === '/api/notes' && req.method === 'GET') {
    const list = await db.note.findMany()
    res.setHeader('Content-Type', 'application/json')
    res.end(JSON.stringify(list))
    return
  }

  res.statusCode = 404
  // 忘了 end()
})
